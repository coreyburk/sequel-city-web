# commit-helper-work-package-traceability-line

## Objective

Require accepted work package commits to include the resolved work package ID in a standard commit-message location.

## Scope

### In Scope
- Update the accepted-WP commit helper so it derives the resolved WP ID and emits `WP: WP-###` as the first body line after the title.
- Update commit-message guidance and finalization skill guidance to make the traceability line mandatory.
- Add focused test coverage for the helper preview format.
- Refresh the live handoff for this commit.

### Out of Scope
- Changing general non-WP commit conventions.
- Rewriting historical commit messages.
- Changing git remotes, branch policy, repository naming, or release process.
- Adding dependencies or runtime application behavior.
- Regenerating the Understand graph baseline.

## Required Behavior

- `scripts/commit-work-package.ps1` must derive the normalized `WP-###` ID from the resolved work-package path.
- Commit messages generated by the helper must use this body shape:

```text
Imperative title

WP: WP-###

- concrete change bullet
```

- The WP traceability line must be the first body line after the title and blank separator.
- Documentation and the finalization skill must describe the same required commit shape.
- A regression test must fail if helper preview output omits the resolved WP ID before the first change bullet.
