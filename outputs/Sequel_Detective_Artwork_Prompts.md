# Sequel Detective Artwork Prompts

Use these with Gemini / Nano Banana as slide artwork prompts. Keep the same visual language across the set: cinematic noir detective atmosphere, local browser technology, readable composition, no fake app screenshots, no logos unless provided, no text embedded in the image unless explicitly requested.

## Global Style

Modern noir educational technology, SQL database investigation, warm desk lamp light, cool rainy window light, realistic illustrated digital painting, clean cinematic composition, high contrast but not crushed blacks, professional capstone presentation quality, 16:9 aspect ratio, no words, no logos, no UI text, no distorted hands, no watermark.

## Slide 1 - Title Image

Create a 16:9 noir detective office scene for a SQL learning web application. On the right side, a mentor detective sits at a desk with an open case file, database tables printed on paper, a laptop showing abstract query-grid shapes without readable text, and a rain-streaked window behind him. Leave the left third darker and visually quiet for presentation title text. Cinematic lighting, warm desk lamp, cool blue window light, realistic illustrated style, no readable text, no logos.

## Slide 2 - Problem To Learning Goal

Create a split-scene image showing the contrast between isolated SQL worksheet practice and investigation-based learning. Left side: a cold desk with scattered disconnected query fragments and blank worksheets, sterile blue light. Right side: an evidence board with connected database table cards, clues, and a student notebook, warm detective lighting. Keep the center open enough for overlay text. No readable text, no logos, no UI.

## Slide 3 - Deterministic Learning Core

Create a visual metaphor for deterministic backend validation in a SQL detective learning app. Show a secure evidence vault with database rows, a clear checklist, and a query passing through a guarded checkpoint before reaching evidence. The mood should be trustworthy and analytical, not futuristic AI. Include subtle browser and server motifs, but no readable text. 16:9, noir, professional.

## Slide 4 - Student Plays The Investigation

Create a student-facing investigation scene: a learner at a laptop in a dark classroom or study room, reviewing a case file, schema cards, and clue notes while a detective mentor presence appears as a framed case-board photo or subtle background figure. The image should communicate active investigation and student agency. Leave room on the left for bullet text. No readable text.

## Slide 5 - Local Web Architecture

Create a clean conceptual illustration for a local web architecture, not a literal diagram. Show three physical layers on a detective desk: a browser window represented by a laptop, a small local server box or terminal notebook in the middle, and a secure SQL database evidence cabinet below or behind it. Use thin glowing connection lines between them. The image should imply local-only localhost operation and deterministic control. No AI imagery, no cloud icons, no readable text.

## Slide 6 - Backend Authority

Create a noir evidence-control scene where backend services act as a gatekeeper. A stamped approval checkpoint sits between a learner's query card and a protected SQL evidence archive. Visual hints of safety validation, read-only execution, schema metadata, and suspect verification should be represented as physical folders or seals, not text labels. No readable text.

## Slide 7 - Student Learning Loop

Create a circular investigation workflow scene on a tabletop: case briefing folder, schema map, SQL query card, validation stamp, result table printout, evidence note, and suspect theory card arranged in a loop with subtle arrows made of string or light. It should feel like an investigation process, not an AI pipeline. Leave center or lower-right space for slide labels. No readable text.

## Slide 8 - Demonstration Transition

Create a dramatic demo transition image: the Sequel City case file open on a desk, laptop browser glowing, Query Lab-like abstract grid visible but unreadable, evidence board in the background, mentor detective pointing toward the screen. Use a strong focal path from case file to laptop. No readable text, no logos.

## Slide 10 - AI-Assisted Development

Create an image representing human-governed AI-assisted software development without robot mascots. Show a developer workstation with four distinct research notebooks/tools around a central SSOT binder, code editor glow, architecture sketches, and verification checklists. The image should communicate controlled engineering workflow and human review. No company logos, no readable text.

## Slide 11 - Successes And Challenges

Two coordinated images may work better than one because the slide has a two-column structure. Generate them as a matched pair with the same camera angle, lighting style, palette, and noir presentation mood. Both should be 16:9 or wide 4:3 crops that can be placed inside separate left/right slide panels. Do not include readable text, labels, logos, or fake UI screenshots.

### Slide 11A - Successes Panel

Create a noir success image for the left side of a capstone presentation slide. Show an orderly detective desk with a clean case file, a laptop showing abstract table-grid shapes without readable text, a sealed evidence folder, a small local server indicator light, and neatly pinned clue cards. The mood should communicate that the system works: local-first browser runtime, deterministic SQL safety, a playable case route, and database-backed verification. Warm desk lamp, cool blue accents, professional illustrated realism, uncluttered composition, no readable text.

### Slide 11B - Challenges Panel

Create a paired noir challenges image for the right side of the same slide. Use the same desk, camera angle, and lighting style, but show the harder engineering work: tangled red string across schema papers, browser layout sketches, local SQL Server setup notes, blocked-query cards, and a checklist with checkmarks but no readable text. The mood should show difficult tradeoffs and disciplined problem-solving, not failure or chaos. Warm noir lighting, subtle amber accents, professional illustrated realism, no readable text.

## Slide 12 - Future Plans

Create a hopeful future-roadmap image for Sequel Detective. Show a case library shelf expanding with new case files, a persistent notebook, an instructor dashboard silhouette on a wall monitor, and classroom deployment hints. Keep it grounded and local-first, not cloud SaaS. Warm noir lighting, clean composition, no readable text.

## Slide 13 - Questions

Create a calm closing image: detective office desk after the case, closed case file, softly glowing laptop, evidence board in the background, rain at the window. Leave large quiet space on the left for “Questions?” text. No readable text, no logos.
